\section{Literature Review}
The literature review examines existing research on each game-playing AI approach to understand their general strengths and limitations. This evaluation helps to anticipate potential challenges before implementing the agents. The literature review then considers a more complex hybrid approach that demonstrates how different AI approaches can work together to build a potentially stronger agent. Finally, existing Azul implementations are reviewed to identify limitations in previous work and establish the research gap that this project intends on filling. 

\subsection{Minimax}
Yannakakis and Togelius' \emph{Artificial Intelligence and Games} describes Minimax as an algorithm for two-player adversarial games\cite{yannakakis2025artificial}. Minimax considers the possible moves available to each player in turn while assuming that both players play optimally. In a finite, deterministic, two-player, zero-sum game with perfect information, an optimal move can be found by exploring the entire game tree. However, searching the entire game tree quickly becomes infeasible as the complexity of the game increases due to the branching factor and search depth. \\

Shannon's \emph{Programming a Computer for Playing Chess} takes this idea further by considering the application of Minimax to chess\cite{shannonminimaxchess}. Since exploring the entire game tree is infeasible, Shannon proposes searching only a certain number of moves ahead and using an evaluation function to estimate the quality of the resulting game states. Shannon also considers selective search, which prioritises moves that appear more promising and hence reduce the game tree that needs to be explored. However, this comes with a risk of excluding an important alternative move. Knuth and Moore's \emph{An Analysis of Alpha-Beta Pruning} examines a further improvement that reduces the number of branches searched by excluding those that cannot influence the final Minimax decision\cite{knuthalphabeta}. However, the effectiveness of alpha-beta pruning relies on the order in which moves are considered. \\

Campbell, Hoane and Hsu's \emph{Deep Blue} demonstrates how search-based AI was developed into a chess playing system capable of playing chess at world-championship level\cite{deepblue}. It defeated the reigning World Chess Champion Garry Kasparov in 1997. Deep Blue extended Minimax with alpha-beta pruning through parallel processing, a more complex evaluation function and a grandmaster game database. Although an equivalent database is less likely to be available for Azul, the other improvements may help address the inefficiencies of basic Minimax when developing an Azul agent. Collectively, these sources can therefore inform the implementation of Minimax as a search-based baseline for comparison with the other Azul agents. However, the implementation must also determine how to represent Azul's random factory replenishment since standard Minimax assumes deterministic transitions.
